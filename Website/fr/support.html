Cirruscope est conçu pour les environnements online-first – là où l'interface web de Nextcloud est ta principale façon de travailler, plutôt que des copies locales de tes fichiers. Le client officiel Nextcloud Files a pour rôle de synchroniser les fichiers de façon bidirectionnelle entre le serveur et ton appareil. Le client Nextcloud Talk partage l'objectif de Cirruscope de mieux s'intégrer au bureau, mais il se concentre avant tout sur Nextcloud Talk. Les clients officiels Nextcloud sont des projets multiplateformes ; Cirruscope est exclusif à macOS et troque cette étendue contre l'intégration plus étroite et plus native que permet la spécialisation. Cirruscope apporte cette sensation native et intégrée à toute l'expérience web de Nextcloud.

Compatibilité

Cirruscope s'appuie sur les technologies les plus récentes aux deux extrémités de la connexion. Voici exactement ce pour quoi l'app est développée et testée aujourd'hui.

macOS

macOS 26 Tahoe ou plus récent

Conçu pour la génération actuelle de macOS et son langage de design natif.

Serveur Nextcloud

Version 34 ou plus récente

La version minimale prise en charge à ce jour ; les versions plus récentes le sont dès leur sortie.

Applications Nextcloud testées

Ces applications Nextcloud officielles sont prises en charge et testées avec Cirruscope :

  • Dashboard
  • Files
  • Talk
  • Activity
  • Photos
  • Mail
  • Contacts
  • Calendar
  • Notes
  • Deck
  • Collectives
  • Tasks
  • Office
  • Text
Les interfaces web Nextcloud personnalisées ne sont pas testées pour la compatibilité. Des thèmes, des applications tierces ou une interface web modifiée peuvent influer sur le comportement de Cirruscope.
