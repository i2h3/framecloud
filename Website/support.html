Cirruscope is built for online-first environments — where the Nextcloud web interface is your main way of working, rather than local copies of your files. The official Nextcloud Files client's purpose is to keep files synchronized bidirectionally between the server and your device. The Nextcloud Talk client shares Cirruscope's goal of integrating better into your desktop, but focuses primarily on Nextcloud Talk. The official Nextcloud clients are multi-platform projects; Cirruscope is exclusive to macOS, trading that breadth for the tighter, more native integration specialization makes possible. Cirruscope brings that native, integrated feel to the whole Nextcloud web experience.

Compatibility

Cirruscope targets the latest technologies on both ends of the connection. Here is exactly what it is built and tested against today.

macOS

macOS 26 Tahoe or newer

Built for the current generation of macOS and its native design language.

Nextcloud server

Version 34 or newer

The minimum supported release as of today; newer versions are supported as they ship.

Tested Nextcloud apps

These first-party Nextcloud apps are supported and tested to work with Cirruscope:

  • Dashboard
  • Files
  • Talk
  • Activity
  • Photos
  • Mail
  • Contacts
  • Calendar
  • Notes
  • Deck
  • Collectives
  • Tasks
  • Office
  • Text
Customized Nextcloud server front-ends are not tested for compatibility. Themes, third-party apps, or a modified web interface may affect how Cirruscope behaves.
